# 如何使用本站学习

本站是一个中文原创的全栈开发知识库，为个人长期自学设计。这一页说明它的组织方式和推荐的使用方法。

## 本站不是什么

先说清楚边界，避免你带着错误预期使用它：

- **它不是速查手册**。每个知识点都会解释「为什么这样设计」和「出错了怎么排查」，而不是只给结论。如果你只是想快速查一个 API 的写法，直接看官方文档更快。
- **它不是 JavaScript 的替代教程**。语言主线仍然建议跟 [javascript.info](https://javascript.info/) 读，本站不复制它的正文。[本站的 JavaScript 领域](/javascript/)是在它之上写的 12 章中文补充正文（含阶段项目）：一张与它的章节对照地图，加它一带而过但你一定会踩的语言层故障（引用与拷贝、闭包、`this`、微任务顺序、原型链、模块互操作），以及 DOM 与事件、网络与存储、错误与 DevTools 调试、无障碍与性能，最后衔接 [TypeScript](/typescript/)。
- **它不复制任何第三方教程正文**。所有讲解都是中文原创组织，引用处直接链接到对应的官方文档页面。

## 课程的组织方式

每个技术领域是一个独立目录，目录内按「模块 → 章节」组织。每篇文章的结构基本一致：

1. **问题引入**：先说清楚不学这个会遇到什么具体问题，而不是直接抛概念。
2. **原理讲解**：这个机制是怎么工作的，为什么这样设计。
3. **真实代码示例**：符合对应技术真实语法的可解释代码。
4. **常见错误与排查**：真实开发中最容易踩的坑，以及怎么定位。
5. **练习**：章末动手题，答案与解析默认折叠。
6. **官方文档与延伸阅读**：指向具体知识点页面，而不是官网首页。

每个领域末尾有一个**里程碑项目**，把该领域的知识串成一个能跑起来的东西。

## 关于代码示例的验证状态

本站对代码示例的真实性有明确标注规则，请养成看标注的习惯：

<Callout type="verified" title="已运行验证">

示例代码在真实环境中执行过，输出结果与文中一致。

</Callout>

<Callout type="unverified" title="未经运行验证">

代码语法与 API 用法对照官方文档核实过，但没有实际运行。**本站不会声称这类代码「测试通过」**。你在使用前应当自己跑一遍。

</Callout>

涉及版本差异的内容会写明适用版本，例如「Fastify v5」「Node.js 22 LTS」。版本相关的行为是最容易过时的部分，遇到疑问请优先查官方文档。

还有一条口径要说明：终端输出示例里出现的**用户名、邮箱、家目录与软件安装路径都是占位值**（如 `learner`、`learner@example.com`、`C:\Users\learner`、`D:\work\learns`），不是编写者电脑上的真实信息。命令本身、输出结构、字段顺序和 uid/gid 这类数字保持原样。你在自己机器上跑同一条命令，提示符与属主列显示的是你自己的用户名和路径——「本机输出不可直接带走」这一点，Linux 与 DevOps 两域的课程里反复讲过。

## 推荐的学习方法

**按顺序读，不要跳。** 各领域的前置依赖在[学习路线](/guide/roadmap)页有明确标注。跳过前置章节会导致后面大量内容看不懂，反而更慢。

**练习先自己做，再看答案。** 答案默认折叠就是为了这个。看着答案抄一遍代码产生的「我懂了」是假性掌握——判断标准很简单：合上答案，你能不能从零写出同样的东西并解释每一行为什么在那儿。

**遇到报错先读错误信息。** 每章的「常见错误与排查」小节会教你怎么读这类错误。真实开发中 80% 的时间花在定位问题上，这个能力比记住 API 重要得多。

## 平台功能说明

| 功能 | 说明 |
| --- | --- |
| 站内搜索 | 顶部搜索框，快捷键 `Ctrl + K`（macOS 为 `Cmd + K`）。基于 MiniSearch 的本地搜索，已针对中文做了单字 + 双字分词，搜索不依赖网络。 |

| 代码复制 | 鼠标悬停在代码块上，右上角出现复制按钮。 |

## 本地启动方式

本站是 VitePress 静态站点，在仓库根目录执行：

```bash
npm install        # 首次安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
npm run build      # 构建静态产物到 .vitepress/dist
npm run preview    # 本地预览构建产物
```

构建产物 `.vitepress/dist` 是纯静态文件，可以直接用 Nginx 托管到 VPS，也可以放到任何静态服务器上。
